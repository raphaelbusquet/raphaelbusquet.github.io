Passo a passo

Descubra como qualquer app funciona

Com o REA (Reverse Engineer Anything), o Claude investiga um app ou site por dentro, te explica em palavras simples como uma funcionalidade funciona e monta a sua versão no seu projeto.

1O que você precisa

  1. Claude Code (precisa de plano pago do Claude). O REA também funciona com Codex, Cursor e Gemini CLI.
  2. Node.js 22 ou 24: baixe a versão LTS em nodejs.org. (As versões 23 e 25 não funcionam.)

2Instalar o REA

  1. No terminal, rode:
    npx rea-agents setup
  2. Escolha o Claude Code, revise as mudanças que ele mostra e aprove. Ele faz backup das suas configurações antes.
  3. Feche e abra o Claude Code de novo pra ele carregar o REA.

3Usar

  1. Abra o Claude Code na pasta do seu projeto.
  2. Cole o prompt, trocando o app e a funcionalidade:
    Usa o REA pra investigar como o [nome do app ou site] faz [a funcionalidade que eu quero]. Me explica em palavras simples como funciona, me mostra as evidências e depois monta uma versão disso pro meu projeto.

Ideias pra testar:

  • O CRM que move o cliente sozinho pra próxima etapa do funil.
  • O sistema de agendamento que manda lembrete automático pro cliente.
  • A busca, o filtro ou o editor de um app que você usa todo dia.

Importante

  • O REA é gratuito e open source e roda no seu computador. O Claude Code precisa de plano pago.
  • Pra analisar apps nativos (instalados no computador), o REA pode pedir o Ghidra, o Hopper ou o IDA. Sites e apps em JavaScript não precisam de nada extra.
  • Use pra entender como uma funcionalidade funciona e criar a sua versão, não pra copiar código, marca ou conteúdo de outra empresa. Alguns serviços proíbem engenharia reversa nos termos de uso.
